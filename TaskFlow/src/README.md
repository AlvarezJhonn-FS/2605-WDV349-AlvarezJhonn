# TaskFlow Source Structure

The TaskFlow source code is organized into separate directories to keep the application maintainable and organized.

## Directories

- `components/` - Reusable React components.
- `pages/` - Application pages and screen-level components.
- `services/` - API requests and application service logic.
- `styles/` - Application styling and responsive design resources.

This structure supports the planned React frontend and provides a foundation for continued TaskFlow development.
