# TaskFlow

TaskFlow is a task management web application designed to help students, freelancers, and small teams organize their work, track their progress, and stay focused on their goals.

## Project Overview

TaskFlow aims to provide a simple, accessible way to manage daily tasks and improve productivity. The project is being developed iteratively, with an emphasis on usability, maintainable code, and validating features through testing and research.

## Current Features

- Create new tasks.
- Mark tasks as completed or incomplete.
- View task completion progress.
- Responsive interface for different screen sizes.

## Technology Stack

- **Frontend:** React and JavaScript
- **Build Tool:** Vite
- **Styling:** CSS
- **Version Control:** Git and GitHub

## Project Structure

The application code is located in the `TaskFlow/` directory.

- `TaskFlow/src/components/` — reusable UI components.
- `TaskFlow/src/pages/` — application pages and screen-level components.
- `TaskFlow/src/services/` — API requests and service logic.
- `TaskFlow/src/styles/` — application styles.
- `docs/` — research, project documentation, and weekly progress logs.

## Development and Validation

TaskFlow is being developed using feature branches and pull requests. Planned validation work includes testing core task workflows, researching user interaction metrics, and evaluating potential usability improvements.

## Project Status

TaskFlow is an active portfolio project. The initial task creation and completion workflows have been implemented, and the next stage focuses on improving usability, refactoring the codebase, strengthening documentation, and validating the application's value.

## Documentation

Project research, planning documents, technical decisions, and weekly progress logs are maintained in the [`docs/`](docs/) directory.
