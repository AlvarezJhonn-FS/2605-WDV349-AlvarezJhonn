# TaskFlow

## Application Definition Statement

TaskFlow is a web application designed to help users organize and manage their daily tasks, projects and goals in one place. The application will allow users to create tasks, track progress, and stay productive through a clean an user friendly interface. The target audience includes students, freelancers and people who struggle with staying organized using multiple disconnected solutions while also serving as a portfolio development project.

## Target Market

The target market for this application includes students, freelancers, entry level professionals and small teams who regularly manage schedules assignments, projects or personal goals. Many people that use digital tools daily and prefer web applications that are simple, fast and accessible across devices.

Primary research includes discussion family, coworkers and friends, and online forums who constantly need to keep track of projects or assignments, and how they currently organic them. Many expressed with switching between apps or forgetting deadlines because their systems were inconsistent.

Secondary research includes reviewing articles adn trends related to productivity applications and task management tools. Research shows that productivity and organization applications continue to grow in popularity among students an demote workers due to increase workload and digital collaboration needs.

## Use Cases

## Use Case 1: Creating and Managing Tasks

- User creates an account and logs into the application
- User creates a new task with a title, description, and due date
- User assigns a status such as “In Progress” or “Completed”
- User views all active tasks from the dashboard
- User updates or deletes tasks when needed

## Use Case 2: Tracking Daily Productivity

- User logs into the application
- User views a progress dashboard displaying completed and pending tasks
- User filters tasks by category or due date
- User marks completed tasks and tracks overall productivity progress

## Use Case 3: Organizing Projects

- User creates a project category
- User assigns multiple tasks to the project
- User monitors project completion progress
- User edits project information and task priorities as needed

## Problem Statement

Many students, freelancers, and busy individuals struggle to stay organized because they rely on multiple disconnected tools to manage schedules, assignments, and projects. This often leads to missed deadlines, poor productivity, and unnecessary stress. Research and discussions with peers showed that users prefer a centralized platform that is easy to use and accessible across devices.

## Pain Points

One major pain point is task overload, where users lose track of assignments or responsibilities because they are scattered across different apps or notes. Another issue is poor organization and lack of visual progress tracking, which can make users feel overwhelmed and unmotivated. Users also experience frustration when applications are cluttered, difficult to navigate, or not mobile responsive.

Primary research discussions revealed that many users want a simple and centralized solution that combines organization, reminders, and progress tracking in one place.

## Solution Statement

TaskFlow will solve these problems by providing a centralized productivity platform where users can organize tasks, manage projects, and track progress in a clean and responsive environment. Unlike some overly complicated productivity tools, TaskFlow will focus on simplicity, usability, and accessibility. The application will use modern full-stack technologies such as React, Node.js, Express, and MongoDB to provide fast and interactive functionality while supporting scalable development practices.

## Competition

Direct competitors include applications such as Trello, Todoist, and Notion, which all provide organization and productivity tools. These applications often include advanced collaboration and productivity features.

TaskFlow differs by focusing on simplicity and beginner-friendly organization tools targeted toward students and individuals rather than large enterprise teams. The goal is to provide a lightweight and intuitive productivity experience while also serving as a portfolio-quality full-stack application.

Indirect competitors include traditional note-taking apps, calendar apps, and reminder applications that partially solve organizational problems but do not provide a fully integrated productivity workflow.

### Features & Functionality

Users will be able to create accounts, securely log in, and manage personal task data. This feature solves the need for personalized and protected user experiences.

Users will be able to create, edit, delete, and organize tasks. This feature helps users manage responsibilities more effectively.

The application will display progress indicators and task completion statistics to help motivate users and provide visual feedback.

Users will be able to group tasks into projects or categories for better organization and workflow management.

A responsive dashboard will provide users with an overview of active tasks, deadlines, and completed work across devices.

Users will be able to search for tasks and filter them by category, due date, or completion status for easier navigation and productivity.

## Integrations

The application will include a custom REST API built with Node.js and Express to manage task and user data. MongoDB and Mongoose will be used for database integration and CRUD functionality.

Potential third-party integrations may include:
- Notification or reminder APIs
- Calendar integration APIs
- Deployment through Vercel or Netlify
- GitHub for version control and project workflow management
