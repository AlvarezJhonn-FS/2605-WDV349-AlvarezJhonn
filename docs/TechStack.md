## Application Design

For application design, I plan to use Figma to create wireframes and click-through prototypes for the project. Figma is useful because it allows easy collaboration, clean UI planning, and responsive layout design before development begins. I would also like to explore UI kits and design inspiration from Material UI and Bootstrap to help create a modern and user-friendly interface. Using these tools will help improve the overall user experience and provide a more professional appearance for the final application.



## Front End Framework

For front-end development, I plan to use HTML, CSS, JavaScript, and React. React will allow me to build reusable components and improve the overall interactivity of the application. I also plan to organize components using a clean file structure and follow best practices with ESLint for code consistency and readability. CSS will be used for styling and responsive design to ensure the application works well across different screen sizes. Learning and using React will strengthen my front-end development skills and add value to my portfolio.



## State Management

For state management and data handling, I plan to use React state management features along with MongoDB for database storage. I may also use local storage for saving temporary user preferences or session data. As the project grows, I may explore Redux or Context API to better manage application state across multiple components. MongoDB is appealing because it is flexible and integrates well with JavaScript applications using the MERN stack approach.



## Node

For backend development, I plan to use Node.js because it allows JavaScript to be used on both the front end and backend. Node.js will help serve the application and manage APIs efficiently. I also plan to use npm and npx to install packages, manage dependencies, and run development tools. Using Node.js will help me gain experience with full-stack JavaScript development and modern backend practices.



## Express

I plan to use Express.js to build the server-side API for the application. Express will help manage routes, middleware, controllers, and communication between the frontend and database. The API will send and receive JSON data and handle requests such as user authentication, creating tasks or posts, and updating information in the database. Learning Express will help me better understand backend architecture and API development practices used in professional environments.



## SQL/Postgres/Sequelize

Although the course references SQL, PostgreSQL, and Sequelize, I currently plan to use MongoDB because it works well with JavaScript-based applications and provides flexible document storage. I would like to continue learning about relational databases and ORMs such as Sequelize in the future. For this project, I plan to focus on building models, validation, and full CRUD functionality using MongoDB and Mongoose. This will still allow me to practice database relationships, data validation, and structured backend development.
