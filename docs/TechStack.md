## Application Design

For application design, I plan to use Figma to create wireframe and click-through prototypes for the project. Figma is useful because it allows easy collaboration, clean UI planning, and responsive layout design before development begins. I would also like to explore UI kits and design inspiration from Material UI and Bootstrap to help create a modern and user-friendly interface. Using these tools will help improve the overall user experience and provide a more professional appearance for the final application.



## Front End Framework

For front-end development, I plan to use HTML, CSS, JavaScript, and React. React will allow me to build reusable components and improve the overall interactivity of the application. I also plan to organize components using a clean file structure and follow best practices with ESLint for code consistency and readability. CSS will be used for styling and responsive design to ensure the application works well across different screen sizes. Learning and using React will strengthen my front-end development skills and add value to my portfolio. (Might use tailwind)




## State Management

For state management and data handling, I plan to use React state management features along with MongoDB for database storage. I may also use local storage for saving temporary user preferences or session data. As the project grows, I may explore Redux or Context API to better manage application state across multiple components. MongoDB is appealing because it is flexible and integrates well with JavaScript applications using the MERN stack approach.



## Node

For backend development, I plan to use Node.js because it allows JavaScript to be used on both the front end and backend. Node.js will help serve the application and manage APIs efficiently. I also plan to use npm and npx to install packages, manage dependencies, and run development tools. Using Node.js will help me gain experience with full-stack JavaScript development and modern backend practices.



## Express

I plan to use Express.js to build the server-side API for the application. Express will help manage routes, middleware, controllers, and communication between the frontend and database. The API will send and receive JSON data and handle requests such as user authentication, creating tasks or posts, and updating information in the database. Learning Express will help me better understand backend architecture and API development practices used in professional environments.

## Milestone 1 Change Order

### Technology Stack Confirmation

The current TaskFlow technology stack remains focused on a JavaScript-based full-stack application.

The planned technologies are:

- **Design:** Figma
- **Frontend:** HTML, CSS, JavaScript, and React
- **Backend:** Node.js and Express
- **Database:** MongoDB
- **Database Library:** Mongoose
- **Package Management:** npm and npx

### Technology Decisions

MongoDB remains the planned database for TaskFlow instead of SQL/PostgreSQL/Sequelize. This decision supports the planned JavaScript-based application architecture and allows the project to use MongoDB and Mongoose for data modeling, validation, and CRUD functionality.

React remains the planned frontend framework, while Node.js and Express will provide the backend API.

Tailwind CSS may be explored for styling, but it is not considered a required part of the core technology stack at this time.

Material UI and Bootstrap will remain available as sources of UI inspiration or potential tools if needed during development.

### Remaining Work

Remaining technical work includes continuing frontend development, implementing backend functionality, connecting the application to MongoDB, completing CRUD functionality, testing the application, improving responsive design, and preparing the final project documentation.

Additional technologies or integrations will only be added if they support the project's core requirements and fit within the remaining development time.
