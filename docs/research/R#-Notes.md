## Sub-Topic 1 - Wireframe
Wireframe is an important step in the process of creating an app/website, because it helps organize the layout and improve usability before creating the final design.

* Low fidelity wireframe focuses on structure and functionality instead of detailed visuals.
* Wireframe helps identify navigation and layout issues early in development.
* Planning interface structure, improve user experience and organization.

<br>

## Sub-Topic 2 - Branding and Visuals
Branding helps define the overall personality and appearances of an application.

* Consistent branding improves personality, professionalism and usability.
* Typography, colors and images identifies how users feels about a product.
* A strong visual helps users recognize and remember the applications.

## Sub-Topic 3 - Typography and Fonts
Typography is an important part of user experience and branding

* Sans-serif fonts create a clean and modern appearance.
* Font hierarchy improves readability and content organization.
* Consistent typography creates a more professional interface. 

## Sub-Topic 4 - Design Theory
Design Theory is a psychological principal and structural rule that dictates how users interact with and perceive interfaces.

* The Aesthetic Usability effect proves that users perceive attractive design as more intuitive and usable.
* Choice Overload causes mental fatigue, meaning minimal options keep user decision path clear.
* Chunking breaks massive data sets into small, distinct units to maximize memory retention and cognitive comfort.
* Jakob's law dictates that users expect your application to look and operate like the standard website they already know.
