## Sub-Topic 1 - Wireframing
Wireframing is an important step in the process of creating an app/website, because it helps organize the layout and improve usability before creating the final design.

* Low fidelity wireframing focuses on structure a dfunctionality instead of detailed visuals.
* Wireframing helps identify navigation and layout issues aearly in development.
* Planning interface structure, improve user experience and organizaion.

## Sub-Topic 2 - Branding and Visuals
Branding helps deine the overal personality and apperances of an application.
